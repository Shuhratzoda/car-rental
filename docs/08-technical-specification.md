## барои коркарди веб-низоми бозори иҷораи автомобилҳо «Autoren»

**Версия:** 1.0  
**Сана:** 17.11.2026  
**Иҷрокунанда:** Шӯҳратзода Довуд Шӯҳратҷон  
**Фармоишгар:** ташкилоти шартии хизматрасонии иҷораи автомобилҳо  
**Фан:** Технологияҳо ва забонҳои Internet барномасозӣ

---

## 1. Маълумоти умумӣ

### 1.1. Номи система

Номи пурра: веб-низоми иттилоотии ҷустуҷӯ, фармоиш ва идоракунии иҷораи автомобилҳо.  
Номи кӯтоҳ: **Autoren**.

### 1.2. Маълумот дар бораи фармоишгар ва иҷрокунанда

Фармоишгар — ташкилоти шартии хизматрасонии иҷораи автомобилҳо, ки мехоҳад маълумоти автомобилҳо, фармоишҳои муштариён ва фаъолияти менеҷеронро дар як низоми ягона идора намояд.

Иҷрокунанда — Шӯҳратзода Довуд Шӯҳратҷон, донишҷӯи фанни «Технологияҳо ва забонҳои Internet барномасозӣ».

### 1.3. Асос барои коркард

Асос барои коркард супориши таълимии лоиҳаи курсӣ ва натиҷаҳои корҳои лабораторӣ оид ба таҳлили предметӣ, таҳияи талабот, моделсозии UML, тарҳрезии пойгоҳи додаҳо ва ҷойгиркунии веб-барнома мебошад.

### 1.4. Мӯҳлатҳои иҷро

Кор дар доираи рӯзҳои 1–16-и нақшаи таълимӣ иҷро карда мешавад. Марҳилаи лоиҳакашӣ то рӯзи 8, таҳия ва санҷиш то рӯзи 15 ва омодасозии нашр то рӯзи 16 пешбинӣ шудааст. Санаҳои тақвимӣ мувофиқи ҷадвали дарсии гурӯҳ муайян карда мешаванд.

### 1.5. Тартиби супоридан

Натиҷаи кор ҳамчун веб-барномаи коркунанда, пойгоҳи додаҳо, ҳуҷҷатҳои техникӣ ва диаграммаҳои лоиҳа пешниҳод мешавад. Нусхаи код ва ҳуҷҷатҳо дар репозитории Git нигоҳ дошта шуда, ба GitHub интиқол дода мешавад.

## 2. Таъинот ва мақсадҳои эҷоди система

### 2.1. Таъиноти система

Autoren барои автоматӣ кардани раванди иҷораи автомобилҳо пешбинӣ шудааст. Низом ба муштарӣ имкон медиҳад, ки автомобилҳоро тамошо карда, аз рӯи хусусиятҳо ҷустуҷӯ намояд ва барои муҳлати муайян фармоиш гузорад. Менеҷер ва маъмур метавонанд автомобилҳо, фармоишҳо, муштариён ва пардохтҳоро идора кунанд.

### 2.2. Мақсадҳои эҷоди система

Мақсадҳои асосӣ:

1. Ҷамъоварии маълумоти автомобилҳо дар каталоги ягона.
2. Кам кардани вақти ҷустуҷӯ ва интихоби автомобил барои муштарӣ.
3. Сабти фармоишҳо ва назорати ҳолати онҳо дар як низом.
4. Кам кардани хатогиҳои дастӣ ҳангоми ҳисоб кардани арзиши иҷора.
5. Таъмини дастрасии мувофиқи нақши корбар.
6. Нигоҳ доштани таърихи фармоиш, супоридан ва баргардонидани автомобил.
7. Додани имконияти гирифтани ҳисобот оид ба фармоишҳо ва даромад.

### 2.3. Нишондиҳандаҳои мақсаднок

| Нишондиҳанда | Арзиши мақсаднок | Усули санҷиш |
|---|---:|---|
| Вақти кушодани саҳифаи каталоги автомобилҳо | то 3 сония дар муҳити санҷишӣ | чен кардани вақти боршавӣ |
| Вақти сабти фармоиш | то 5 сония пас аз фиристодани форма | санҷиши вақти ҷавоби сервер |
| Дурустии ҳисобкунии арзиши иҷора | 100% барои ҳолатҳои санҷишӣ | муқоисаи ҳисоб бо натиҷаи интизорӣ |
| Пешгирии фармоиши такрорӣ барои як автомобил дар як вақт | 100% дар санҷишҳои такрорӣ | санҷиши фармоишҳои ҳампӯш |
| Нигоҳдории маълумоти фармоиш | ҳамаи фармоишҳои тасдиқшуда сабт мешаванд | санҷиши сабтҳо дар ПД |

### 2.4. Ҳудуди лоиҳа

Ба версияи таълимии Autoren дохил мешаванд:

- бақайдгирӣ ва воридшавӣ ба система;
- идоракунии профили корбар;
- каталоги автомобилҳо;
- ҷустуҷӯ ва филтр;
- сабти фармоиши иҷора;
- тасдиқ ё рад кардани фармоиш аз ҷониби корманди ваколатдор;
- сабти супоридан ва баргардонидани автомобил;
- ҳисоб кардани маблағи иҷора;
- сабти пардохт;
- намоиши таърихи фармоишҳо ва ҳисоботи одӣ.

Ба версияи аввал дохил намешаванд:

- пайвастшавӣ ба GPS ва назорати зиндаи автомобил;
- пардохти воқеии онлайн тавассути бонк;
- имзои электронии шартнома;
- барномаи алоҳидаи мобилӣ;
- ҳамгироӣ бо суғурта ва хадамоти давлатӣ.

## 3. Тавсифи объекти автоматикунонӣ

### 3.1. Соҳаи фаъолият

Объекти автоматикунонӣ фаъолияти ташкилот ё соҳибкороне мебошад, ки автомобилҳоро ба иҷора медиҳанд. Дар ҳолати дастӣ муштарӣ маълумоти автомобилҳоро аз корманд мегирад, нарх ва муҳлати иҷораро мувофиқа мекунад ва фармоиш тавассути занг ё ҳуҷҷат сабт мешавад. Ин тартиб метавонад боиси такрор шудани фармоиш, гум шудани маълумот ва хатои ҳисобкунӣ гардад.

Autoren ин маълумот ва амалиётро дар веб-низоми ягона муттаҳид мекунад.

### 3.2. Иштирокчиёни раванд

Дар низом нақшҳои зерин муайян карда мешаванд:

| Нақш | Вазифа ва имконият |
|---|---|
| Муштарӣ (customer) | бақайдгирӣ, дидани каталог, ҷустуҷӯ, фиристодани фармоиш ва дидани таърихи худ |
| Соҳиби автомобил / ширкат (owner) | идора кардани автомобилҳои ба ӯ тааллуқдошта ва дидани фармоишҳои вобаста |
| Менеҷер (manager) | коркарди фармоишҳо, тасдиқ ё рад, сабти супоридан ва баргардонидан |
| Маъмур (admin) | идоракунии корбарон, нақшҳо, маълумотномаҳо ва назорати умумии система |
| Маъмури асосӣ (super_admin) | идоракунии маъмурон ва танзимоти сатҳи олии низом |

Ҳуқуқҳои ниҳоӣ бояд дар матрисаи бахши 4.2 ва дар сохтори воқеии пойгоҳи додаҳо якхела бошанд.

### 3.3. Равандҳои асосии корӣ

**Раванди 1. Илова кардани автомобил.** Соҳиб ё корманди ваколатдор ба система ворид шуда, маълумоти автомобилро ворид мекунад: тамға, модел, соли истеҳсол, тавсиф, нархи иҷора ва аксҳо. Пас аз санҷиш автомобил дар каталог намоиш дода мешавад.

**Раванди 2. Ҷустуҷӯ ва интихоби автомобил.** Муштарӣ ба каталог мегузарад, автомобилҳоро аз рӯи тамға, модел, нарх ва дастрасӣ филтр мекунад ва саҳифаи маълумоти автомобилро мекушояд.

**Раванди 3. Фармоиши иҷора.** Муштарӣ санаи оғоз ва анҷоми иҷораро интихоб карда, фармоиш мефиристад. Система давомнокӣ ва маблағи пешакиро ҳисоб мекунад ва фармоишро бо ҳолати «интизор» сабт менамояд.

**Раванди 4. Коркарди фармоиш.** Менеҷер маълумоти фармоишро месанҷад. Агар автомобил дар муҳлати интихобшуда дастрас бошад, фармоиш тасдиқ мешавад; дар акси ҳол рад ё барои ислоҳ баргардонида мешавад.

**Раванди 5. Супоридан ва баргардонидан.** Ҳангоми супоридани автомобил корманд сана, ҳолат ва нишондиҳандаи одометрро сабт мекунад. Ҳангоми баргардонидан маълумоти нав, ҳолати автомобил ва маблағи ниҳоӣ сабт карда мешаванд.

**Раванди 6. Ҳисоббаробаркунӣ.** Пардохтҳо ба фармоиш вобаста карда мешаванд. Менеҷер метавонад маълумоти пардохт ва ҳисоботи фармоишҳоро бинад.

### 3.4. Луғати истилоҳот

| Истилоҳ | Маъно |
|---|---|
| Автомобил | воситаи нақлиёте, ки ба иҷора пешниҳод мешавад |
| Каталог | рӯйхати автомобилҳои дастрас дар система |
| Фармоиш (booking) | дархости муштарӣ барои иҷораи автомобил дар муҳлати муайян |
| Муҳлати иҷора | сана ва вақти оғозу анҷоми истифодаи автомобил |
| Супоридан (handover) | сабти расмии додани автомобил ба муштарӣ |
| Баргардонидан (return) | сабти қабули автомобил пас аз анҷоми иҷора |
| Тариф | нархи иҷораи автомобил барои як рӯз ё воҳиди муайяни вақт |
| Пойгоҳи додаҳо (ПД) | маҷмӯи маълумоти сохторёфтаи система |
| Нақш | маҷмӯи ҳуқуқҳои корбар дар система |

### 3.5. Хулосаи муқоисавӣ

Дар муқоиса бо сабти дастӣ, Autoren маълумотро дар як ҷой нигоҳ медорад, ҷустуҷӯро осон мекунад, ҳолати фармоишҳоро пайгирӣ менамояд ва дастрасиро аз рӯи нақш маҳдуд мекунад. Афзалияти асосӣ — муттаҳид кардани каталоги автомобилҳо ва раванди фармоиш дар як веб-низом мебошад.

## 4. Талабот ба система

### 4.1. Талабот ба система дар маҷмӯъ

#### 4.1.1. Сохтори система

Система аз қисмҳои зерин иборат аст:

1. Интерфейси вебӣ барои муштарӣ ва кормандон.
2. Қисми серверӣ барои коркарди дархостҳо ва қоидаҳои тиҷоратӣ.
3. Пойгоҳи додаҳо барои нигоҳдории корбарон, автомобилҳо, фармоишҳо ва пардохтҳо.
4. Қисми идоракунӣ барои маъмур ва менеҷер.
5. Қисми ҳисоботдиҳӣ барои ҷамъбасти маълумоти иҷора.

#### 4.1.2. Реҷаи кори система

Система ҳамчун веб-барнома дар браузер истифода мешавад. Дар муҳити таҳия он дар компютери маҳаллӣ тавассути XAMPP (Apache ва MySQL/MariaDB) фаъол карда мешавад. Барои истифодаи беруна сервер ва параметрҳои ҷойгиркунӣ дар марҳилаи нашр муайян карда мешаванд.

#### 4.1.3. Эътимоднокӣ

- Ҳангоми хатои воридкунии форма система бояд паёми фаҳмо диҳад ва маълумоти нодурустро ба ПД сабт накунад.
- Амалиёти муҳим, аз ҷумла сабти фармоиш ва пардохт, бояд бо санҷиши серверӣ иҷро шаванд.
- Барои маълумоти ПД нусхаи эҳтиётӣ пеш аз нашри версияи нав ва на камтар аз як маротиба дар як рӯз ҳангоми кори доимӣ пешбинӣ мешавад.
- Агар пайвастшавӣ ба ПД қатъ шавад, система бояд хатои идорашаванда нишон диҳад ва маълумоти махфиро ошкор накунад.

#### 4.1.4. Амният

- Барои қисмҳои шахсӣ воридшавӣ бо номи корбар ё почтаи электронӣ ва парол талаб карда мешавад.
- Паролҳо танҳо дар шакли хэш нигоҳ дошта мешаванд.
- Ҳуқуқи ҳар амалиёт дар тарафи сервер санҷида мешавад.
- Дархостҳои SQL бо дархостҳои параметрӣ иҷро мешаванд.
- Маълумоти форма аз рӯи навъ ва дарозӣ санҷида мешавад.
- Саҳифаҳои идоракунӣ танҳо барои нақшҳои ваколатдор дастрас мебошанд.
- Калидҳо, паролҳои сервер ва маълумоти махфӣ ба репозитории оммавӣ гузошта намешаванд.

#### 4.1.5. Истифодабарӣ ва мутобиқат

Интерфейс бояд сохтори равшан, менюи фаҳмо ва паёмҳои хатои хонданбоб дошта бошад. Саҳифаҳо бояд дар экранҳои компютер ва телефон мутобиқ намоиш дода шаванд. Матн ва маълумоти корбар бояд бо рамзгузории UTF-8 нигоҳ дошта шаванд.

#### 4.2.1. Ҳикояҳои корбар (User Stories)

1. **US-01 — Ҷустуҷӯи автомобил.** Ҳамчун муштарӣ, ман мехоҳам автомобилҳоро аз рӯи тамға, нарх ва санаи дастрасӣ ҷустуҷӯ кунам, то варианти мувофиқро интихоб намоям. Меъёри қабул: натиҷаҳо ба филтрҳои интихобшуда мувофиқат мекунанд.
2. **US-02 — Фармоиши иҷора.** Ҳамчун муштарӣ, ман мехоҳам санаи оғоз ва анҷомро интихоб карда фармоиш фиристам, то автомобилро барои муҳлати зарурӣ дархост намоям. Меъёри қабул: фармоиш бо ҳолати «интизор» сабт мешавад ва маблағи пешакӣ нишон дода мешавад.
3. **US-03 — Идоракунии автомобил.** Ҳамчун соҳиби автомобил, ман мехоҳам маълумоти автомобилҳои худро илова ва навсозӣ кунам, то онҳо дар каталог дуруст нишон дода шаванд. Меъёри қабул: танҳо соҳиби сабт ё маъмури ваколатдор метавонад маълумотро тағйир диҳад.
4. **US-04 — Тасдиқи фармоиш.** Ҳамчун менеҷер, ман мехоҳам фармоишҳои навро дида, тасдиқ ё рад кунам, то дастрасии автомобилҳо назорат шавад. Меъёри қабул: ҳолати фармоиш сабт шуда, дар таърих намоён мегардад.
5. **US-05 — Сабти баргардонидан.** Ҳамчун менеҷер, ман мехоҳам маълумоти баргардонидани автомобилро сабт кунам, то иҷора дуруст анҷом ёбад. Меъёри қабул: сабти баргардонидан ба фармоиши мувофиқ пайваст мешавад.
6. **US-06 — Дидани ҳисобот.** Ҳамчун маъмур, ман мехоҳам шумораи фармоишҳо ва маблағи даромадро барои давраи муайян бинам, то фаъолияти хизматрасониро таҳлил намоям. Меъёри қабул: натиҷаи ҳисобот ба маълумоти фармоишҳо ва пардохтҳо мувофиқат мекунад.

### 4.3. Талабот ба намудҳои таъминот

#### 4.3.1. Таъминоти иттилоотӣ

Пойгоҳи додаҳо бо номи `autoren_db` дар MySQL ё MariaDB пешбинӣ шудааст. Маълумоти асосӣ гурӯҳҳои зеринро дар бар мегирад: корбарон ва нақшҳо, ширкатҳо ё соҳибон, автомобилҳо, аксҳои автомобилҳо, тарифҳо, фармоишҳо, супоридан, баргардонидан, пардохтҳо, хароҷот ва шарҳҳо. Ном ва шумораи ҷадвалҳои ниҳоӣ бояд ба `database/schema.sql` мувофиқ бошанд.

Барои нигоҳдории матни тоҷикӣ рамзгузории `utf8mb4` истифода мешавад. Барои алоқаи ҷадвалҳо калидҳои ибтидоӣ ва хориҷӣ, барои ҷустуҷӯ индексҳои мувофиқ истифода мешаванд.

#### 4.3.2. Таъминоти барномавӣ

- Забони серверӣ: PHP 8.5 (бо мутобиқат ба версияи PHP-и муҳити ҷойгиркунӣ).
- Пойгоҳи додаҳо: MySQL ё MariaDB.
- Қисми муштарӣ: HTML5, CSS3 ва JavaScript.
- Муҳити маҳаллии таҳия: XAMPP.
- Муҳаррири код: Visual Studio Code.
- Идоракунии версия: Git ва GitHub.
- Браузери санҷишӣ: Google Chrome ё браузери муосири ҳаммонанд.
- PHP-фреймворк дар версияи таълимии лоиҳа ҳатмӣ нест; код дар PHP-и одӣ сохта мешавад.

#### 4.3.3. Таъминоти техникӣ

Барои таҳия компютери дорои Windows 11, XAMPP ва пайвасти интернет истифода мешавад. Барои иҷрои маҳаллӣ сервери Apache ва MySQL/MariaDB-и XAMPP фаъол карда мешаванд. Талаботи дақиқи сервери истеҳсолӣ ҳангоми марҳилаи нашр, бо назардошти ҳаҷми истифодабарандагон, муайян карда мешавад.

#### 4.3.4. Таъминоти лингвистӣ

Забони асосии интерфейс тоҷикӣ мебошад. Номҳои майдонҳо, тугмаҳо, паёмҳои система ва хатогиҳо бояд фаҳмо бошанд. Маълумот бо ҳуруфи кириллӣ ва лотинӣ қабул карда мешавад. Рамзгузории UTF-8 барои пешгирии вайроншавии ҳарфҳо истифода мешавад.

#### 4.3.5. Таъминоти ташкилӣ ва методӣ

Корбарон мувофиқи нақш ва ҳуқуқҳои худ амал мекунанд. Маъмур масъули идоракунии корбарон ва танзимоти умумӣ мебошад; менеҷер фармоишҳоро коркард мекунад; соҳиби автомобил маълумоти автомобилҳои худро идора мекунад; муштарӣ фармоиш мегузорад ва таърихи худро мебинад. Дастурамали кӯтоҳи истифода ва қоидаҳои нусхабардории ПД бояд омода карда шаванд.

6. **Санҷиши амният:** корбар бе иҷозат ба саҳифаҳои идоракунӣ дастрасӣ пайдо карда наметавонад; маълумоти воридшуда санҷида мешавад.

5. Диаграммаҳои UML — Use Case, Activity, Sequence, Class ва Component.
6. Диаграммаи ER ва файли сохтори ПД `database/schema.sql`.
7. `database/seed.sql` — маълумоти ибтидоӣ барои санҷиш, бе паролҳои воқеӣ.
8. `database/queries.sql` — дархостҳои SQL барои санҷиши ПД ва гирифтани маълумот.
9. `docs/15-test-cases.md` — сенарияҳои санҷиш.
10. `docs/16-deploy.md` — дастури ҷойгиркунӣ ва танзими муҳити иҷро.
11. Дастури кӯтоҳи корбар — тарзи бақайдгирӣ, ҷустуҷӯ ва фармоиши автомобил.

Ҳуҷҷатҳо бояд бо забони фаҳмо навишта шаванд. Номи файлҳо ва роҳҳои расмҳо бояд ба сохтори воқеии репозиторий мувофиқат кунанд. Дар ҳуҷҷат роҳҳои мутлақи компютери маҳаллӣ истифода намешаванд.
