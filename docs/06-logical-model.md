# Логическая модель данных: car_rental

| Каримов Д. | Toyota Camry | Стандарт | 250 | 2026-11-15 | 2026-11-18 | approved | 35000 / NULL |

## 2. Нормализация
### 1НФ
Поля ФИО разделены на `full_name`. Убран составной характер ячеек.
### 2НФ
Устранены частичные зависимости: все неключевые атрибуты зависят от первичного ключа `id`.
### 3НФ
Устранены транзитивные зависимости. Тарифы вынесены в отдельную таблицу `tariffs`, связь с автомобилями осуществляется через `tariff_id`.

## 4. Связи
- `tariffs` 1:N `cars` (`tariff_id`)
- `users` 1:N `bookings` (`user_id`)
- `cars` 1:N `bookings` (`car_id`)
- `bookings` 1:1 `rentals` (`booking_id`)
- `users` 1:N `rentals` (`manager_id`)

## 5. Ограничения целостности
- `UNIQUE (users.email)`
- `CHECK (date_end >= date_start)`
- `ON DELETE RESTRICT` для внешних ключей каталога автомобилей и тарифов.
